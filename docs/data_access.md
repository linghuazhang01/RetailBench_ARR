# Data Access and Reconstruction Notes

RetailBench uses processed retail, review, and news-derived signals. The review
artifact does not redistribute third-party raw corpora when their license or
terms may restrict redistribution.

## Included

- Paper-facing metrics and diagnostics under `paper_submit_data/outputs/`.
- Analysis scripts used to regenerate paper-facing CSV/JSON summaries and
  figures from the released metric artifacts.
- A fixed configuration summary in `configs/paper_main_hard_v2.json`.

## Not Included

- Full LLM raw rollout logs.
- Large local runtime databases.
- Third-party raw retail, review, and news corpora.
- Local cache directories and generated bytecode.

## Expected Data Layout for Full Simulator Runs

For full environment execution, place reconstructed processed data under:

```text
data/
  dynamic/
    simulate_data/15/
    review/
  still/
    simulate_data/15/
    review/
  still_super_easy/
    simulate_data/15/
    review/
```

The simulator configuration in `util/default_config.py` refers to these relative
paths. Reviewers can still inspect and rerun paper-facing analysis from the
included `paper_submit_data/outputs/` without reconstructing full raw data.
